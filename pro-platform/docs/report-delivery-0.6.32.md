# Pro Analytics 0.6.32-preview

Rebuild the Analytics Report email attachment as four intentionally paginated evidence pages: Brand Axis/focus cards; website acquisition and traffic sources; Facebook/Instagram ranked posts; returning audience, email response and audience profile. Use the company logo when available, native PDF text/vector graphics and embedded DejaVu Sans subsets with bundled license. No image-based page rasterization or remote rendering service.

The loop and displaced marker are schematic, using the same session and returning-to-new ratio changes as the dashboard. They do not measure Brand Loyalty, recall or competitive force. Increased ratio with fewer returning visitors is explained explicitly. Organic-social and email-attributed website sessions belong under Acquisition; campaign response sits separately and is not presented as Retention proof. Net-follower comparisons use absolute differences when crossing zero. Click rates show two decimals and percentage-point differences. Missing evidence stays unavailable. Zero recorded goal events trigger a measurement check.

Post titles use a compact first-paragraph excerpt fitted to the column, with explicit truncation, rank/views/date/title order and whole rows. Unsupported emoji are removed before WinAnsi conversion, avoiding question-mark noise. Company header, period, previous period and preparation timestamp repeat on each page.

Provider queries, metrics, permissions, mail recipients, schedules and Review allowances are unchanged. Existing saved Review narrative uses its existing export structure with the improved embedded fonts; this release redesigns Analytics Reports. No customer fixtures or uploaded reports are published in source. Preview reconstructed privately from the supplied report is for layout review, not a fresh provider collection. Full-precision email click rates in that preview are derived from supplied send/click counts.

Validation: all PHP/JS regression suites, PHP syntax, PDF structural/text checks, font embedding and four-page visual inspection. Live provider and transport delivery still require user installation/test. Stage first, normal plugin update only.
