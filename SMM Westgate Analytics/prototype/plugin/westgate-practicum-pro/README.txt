Westgate Practicum Pro 0.1.1-preview

INSTALL
1. WordPress > Plugins > Add New Plugin > Upload Plugin.
2. Upload westgate-practicum-pro-0.1.1-preview.zip and activate.
3. Open Tools > Practicum Pro Preview while signed in as an administrator.
4. Save your campaign setup, brand brief, and a weekly reflection.
5. Reload to confirm the saved entries remain.

Default website: https://aladdincleans.com
Default email provider: Constant Contact. Mailchimp is also selectable.
Choose actual campaign dates and a primary action before saving.

WHAT THIS PREVIEW DOES
Saves one campaign per account, its Story/Promise/Belief/Trust brief, and weekly
reflections in WordPress user metadata. No companion service is needed.
Reporting weeks start on Sunday. Select a Sunday overlapping campaign dates.

WHAT IT DOES NOT DO
Does not connect GA4, Constant Contact, or Mailchimp; display live metrics;
schedule data collection; score campaigns; grant course completion; or change
certificates, payments, navigation, or legacy analytics. Provider selection
records your choice only. This is a workflow preview, not the analytics release.

ACCESS
The Tools screen is restricted to administrators. An optional separate page can
use [westgate_practicum_pro]. Non-admin testers need the explicit
westgate_practicum_access capability; no membership mapping is active yet.
Do not replace /member-analytics/ or deactivate SMM Master/legacy plugins.
Use a private uncached page for front-end tests; verify host/CDN bypass first.

ROLLBACK
Deactivate this plugin. Saved preview data is retained. No pages, roles,
capabilities, jobs or old analytics records are created or deleted on activation.
Future hosted-service migration must explicitly export/import preview records;
configuring a hosted service does not automatically migrate local records.
